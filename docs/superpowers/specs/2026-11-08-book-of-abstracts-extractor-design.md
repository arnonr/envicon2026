# Book of Abstracts File Extractor — Short Design Spec

**Date:** 2026-11-08
**Size:** Small change (สคริปต์ดึงและจัดเรียงไฟล์ Abstract ล่าสุดตามรหัสผลงาน)

---

## 1. Intent & Why
ดึงไฟล์บทคัดย่อ (Abstract) เวอร์ชันล่าสุดทั้งไฟล์ Word (`.doc/.docx`) และ PDF (`.pdf`) ของผลงานวิจัยทั้ง 113 เรื่องในโปรแกรมการประชุม TSHE-CON 2026 ออกมาจัดเรียงและตั้งชื่อตามรหัสผลงาน (เช่น `ENV-O-01`, `ENV-P-01`) เพื่อให้ทีมงานนำไปจัดหน้าและใส่ปกทำเล่ม **Book of Abstracts** ในโปรแกรมภายนอกต่อได้ทันที

## 2. Goals, Non-Goals, Anti-Goals
- **Goals:**
  - อ่านไฟล์ Excel ล่าสุดที่ Export จากหน้า Admin (ค่าเริ่มต้นอ่านไฟล์ล่าสุดใน `~/Downloads/envicon-submissions-*.xlsx` หรือระบุ path ได้)
  - จับคู่ผลงานทั้ง 113 รหัสจาก `frontend/utils/program-data.ts` แบบ 2 ขั้นตอน: (1) ชื่อเรื่องตรงกันหลัง normalize (2) ชื่อผู้ส่ง/ผู้แต่งตรงกันสำหรับเรื่องที่มีการปรับชื่อเรื่องในระบบ (ตรวจสอบกับไฟล์ `envicon-submissions-2026-11-08.xlsx` แล้วจับคู่ได้ครบ **113 / 113 เรื่อง**)
  - ดาวน์โหลดไฟล์บทคัดย่อล่าสุดและจัดเก็บแยกให้ใช้งานง่ายทั้ง:
    - โฟลเดอร์รวมเรียงตามลำดับและรหัส (`by_type/word/`, `by_type/pdf/`)
    - โฟลเดอร์แยกตาม Session (`by_session/01_ENV/` ... `07_GREEN/`)
    - โฟลเดอร์สำรอง `fallback_fullpaper/` สำหรับผลงานที่อัปโหลดไว้เฉพาะช่อง Full Paper (`DIGI-P-02`, `GREEN-O-03`) และไฟล์ข้อความ `.txt` สำหรับเรื่องที่มีเฉพาะข้อความในระบบ (`CLIM-O-12`)
  - สร้างไฟล์รายงานสรุป `summary_report.xlsx` แสดงสถานะไฟล์ของทั้ง 113 รหัสเรียงตามลำดับ
- **Non-Goals:**
  - ไม่แก้ไขโค้ดฝั่ง Production Server หรือ Database
- **Anti-Goals:**
  - ไม่ใช้การจับคู่ด้วยคำขึ้นต้นของชื่อเรื่องเพียงอย่างเดียว (เช่น `"การประเมินคาร์บอนฟุตพริ้นท์ของ..."`) เพราะจะทำให้จับคู่สลับเรื่องกัน

## 3. Constraints
- รันด้วย Bun (`bun run scripts/extract-book-of-abstracts.ts`) โดยใช้ `exceljs` ที่มีอยู่แล้วใน `backend/node_modules`
- รหัสผลงานที่มี `_` (เช่น `GREEN_P-01` ถึง `GREEN_P-04`) ให้ใช้ชื่อไฟล์มาตรฐานที่มีลำดับนำหน้าและรหัสชัดเจน เช่น `001_ENV-O-01.pdf` / `ENV-O-01.docx`

## 4. Approaches Considered
1. **แนวทางที่ 1 (เลือกใช้): สคริปต์รันบนเครื่อง อ่านลิงก์จากไฟล์ Excel ที่ Export จากหน้า Admin**
   - *ข้อดี:* เร็วที่สุด ไม่ต้องแก้โค้ดหรือ Deploy เซิร์ฟเวอร์ใหม่ และใช้ไฟล์ `~/Downloads/envicon-submissions-2026-11-08.xlsx` ที่มีอยู่แล้วในเครื่องได้ทันที
   - *ข้อเสีย:* ต้องมีไฟล์ Excel ที่กด Export มาจากหน้า Admin
2. **แนวทางที่ 2: สคริปต์เชื่อมต่อ API เซิร์ฟเวอร์โดยตรง**
   - *ข้อดี:* ไม่ต้องกดโหลด Excel ก่อน
   - *ข้อเสีย:* ต้องใช้รหัสผ่านหรือ Token ของ Admin ตอนรัน
3. **แนวทางที่ 3: เพิ่มปุ่มดาวน์โหลด ZIP บนหน้าเว็บ Admin**
   - *ข้อดี:* กดโหลดจากหน้าเว็บได้
   - *ข้อเสีย:* ต้อง Deploy ระบบใหม่และเสี่ยงติด Timeout เมื่อรวมไฟล์ขนาดใหญ่

## 5. Details of How It Works
- **สคริปต์:** `scripts/extract-book-of-abstracts.ts`
- **ผลลัพธ์ปลายทาง (`book-of-abstracts-export/`):**
  - `by_session/01_ENV/` ... `07_GREEN/` -> เก็บไฟล์เรียงตามลำดับในแต่ละ Session เช่น `01_ENV-O-01_อรณิชา สังข์โพธิ์.docx`, `01_ENV-O-01_อรณิชา สังข์โพธิ์.pdf`
  - `all_word/` -> รวมไฟล์ Word ทั้งหมดเรียงลำดับ `001_ENV-O-01.docx` ... `113_GREEN-P-04.docx`
  - `all_pdf/` -> รวมไฟล์ PDF ทั้งหมดเรียงลำดับ `001_ENV-O-01.pdf` ... `113_GREEN-P-04.pdf`
  - `fallback/` -> เก็บไฟล์ Full Paper หรือข้อความ Abstract จากฐานข้อมูลของ 3 เรื่องที่ช่องไฟล์ Abstract ว่าง (`CLIM-O-12`, `DIGI-P-02`, `GREEN-O-03`)
  - `summary_report.xlsx` -> ตารางสรุปทั้ง 113 รหัส พร้อมระบุว่าแต่ละรหัสมีไฟล์ Word / PDF ครบหรือไม่
- **What's left to the builder:** การตั้งค่า concurrency ในการดาวน์โหลดไฟล์ (เช่น ดาวน์โหลดพร้อมกันทีละ 5–8 ไฟล์) และการตรวจสอบขนาดไฟล์หลังดาวน์โหลด
